# auth-server

Dedicated authentication and authorization server.

`v1` scope:

- OAuth 2.1-style authorization server
- OpenID Connect provider
- Local user accounts
- JWT access tokens with JWKS
- RBAC
- DB-backed ABAC policy evaluation
- Single tenant, single customer deployment

This repository starts with planning documents only. The implementation should begin from `Task 1` in [docs/implementation-plan.md](docs/implementation-plan.md).
