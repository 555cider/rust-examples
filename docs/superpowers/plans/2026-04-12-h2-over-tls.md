# HTTP/2 Over TLS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `h2` route protocol and wire ALPN negotiation so the gateway can speak HTTP/2 over TLS on both inbound and upstream paths.

**Architecture:** Keep the existing connector and generic route-serving boundaries, but make TLS config protocol-aware. `protocol: h2` maps to Hyper's HTTP/2 handshake over a TLS stream, while server-side TLS advertises both `h2` and `http/1.1` for inbound negotiation.

**Tech Stack:** Rust, Tokio, Hyper, Hyper Util, Rustls, Tokio-Rustls, rcgen
